# University Exam Coach V3.0.0 — GitHub Pages site

This is a static website containing the public information, support, privacy policy and terms pages.

## Publish using GitHub Pages

1. Sign in to GitHub and create a **public** repository named `university-exam-coach`.
2. Upload the contents of this folder (the files and `assets/` folder; not the outer ZIP).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to deploy. The site address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/university-exam-coach/`

Pages:
- Home: `/`
- Support: `/support.html`
- Privacy Policy: `/privacy.html`
- Terms of Service: `/terms.html`

Support contact: abhishekthakur11@shoolini.online

Before using these links in a public plugin submission, open each page in a private/incognito browser window and verify that it loads publicly. Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

The privacy page describes the plugin's current skills-only architecture. If you later add analytics, a server, database, external API or other data handling, revise the policy before release.
